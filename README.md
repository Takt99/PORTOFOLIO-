# Portofolio Muhammad Ikhsan — HTML, CSS, JavaScript

Website statis tanpa Laravel, Node, Composer, atau database. Cocok untuk VS Code dan GitHub Pages.

## Menjalankan di komputer
1. Ekstrak folder ini.
2. Buka folder `ikhsan-static-portfolio` di VS Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.

## File utama
- `index.html` — konten dan struktur halaman
- `style.css` — tema Dark Premium, responsivitas, dan animasi
- `script.js` — menu mobile, scroll reveal, dan navigasi aktif
- `assets/images/` — foto yang disediakan

## Publikasikan lewat GitHub Pages
1. Buat repository baru di GitHub, misalnya `ikhsan-portfolio`.
2. Unggah seluruh isi folder ini (bukan file ZIP) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses deployment; alamat website akan muncul di bagian Pages.

## Catatan
- Visual peta proyek merupakan ilustrasi konseptual, bukan screenshot aplikasi asli.
- CV PDF belum disertakan sebagai tombol unduh agar tidak mengunggah data kontak pribadi tanpa keputusan eksplisit. Jika ingin tombol CV, letakkan file CV yang sudah disetujui di folder ini lalu tambahkan tautannya.
- LinkedIn dan GitHub tidak ditambahkan karena tautan profil belum diberikan.
- Periksa kembali tanggal, ejaan nama jurnal, dan detail sertifikasi sebelum dipublikasikan.


## Sertifikat dan hasil tes
Dokumen PDF disimpan di `assets/certificates/` dan ditautkan pada bagian Sertifikat di website. Pastikan folder ini ikut diunggah saat memublikasikan website ke GitHub Pages.

## Dokumentasi proyek SigapPadang

Bagian proyek SigapPadang kini memuat galeri 10 tangkapan layar antarmuka aplikasi, termasuk beranda, layanan, peta posko, informasi bencana, daftar posko, halaman tentang, login, dashboard admin, dan dashboard petugas. Gambar disimpan dalam format WebP di `assets/images/sigappadang/` agar ukuran website tetap ringan. Klik gambar untuk membukanya dalam ukuran penuh.
