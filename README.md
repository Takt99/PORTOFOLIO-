Lulusan S1 Pendidikan Teknik Informatika dari Universitas Negeri Padang yang memiliki kompetensi dan minat luas di bidang
teknologi informasi. Memiliki pengalaman dalam pengembangan aplikasi berbasis web menggunakan Laravel, pembuatan website
pemetaan posko bencana di Kota Padang, serta pengumpulan data dan uji coba sistem bersama BPBD Kota Padang. Pernah
terlibat dalam pengembangan website di Badan Penelitian dan Pengembangan Provinsi Sumatera Barat, dukungan administrasi,
praktik lapangan kependidikan di bidang Teknologi Informasi, serta pekerjaan freelance di bidang live gaming dan desain poster.
Memiliki ketertarikan pada pengembangan web, desain antarmuka, sistem informasi, jaringan komputer, dan pemanfaatan
kecerdasan buatan (AI) untuk mendukung pengembangan website dan produktivitas digital. Adaptif, bertanggung jawab, mampu
bekerja sama dalam tim, serta memiliki semangat belajar tinggi. Saat ini mencari peluang magang atau pekerjaan tingkat pemula di
bidang teknologi informasi untuk mengembangkan kompetensi, memperoleh pengalaman profesional, dan berkontribusi dalam
menciptakan solusi teknologi yang efektif dan inovatif.
